# Конструктор курсов — текущее состояние

Версия 0.6, 2026-11-03. Браузерное приложение, GitHub Pages:
https://kabdykarimovaidyn-svg.github.io/konstruktor/
Пользователь разрешил реализовать и опубликовать согласованные изменения.

## Решения и область работ
- Название пока «Конструктор курсов»; новое название не выбрано.
- По умолчанию бело-синее деловое оформление. Один курс объединяет видео и практику.
- Старые проекты schema:2 сохраняются. Локальные проекты/профиль — IndexedDB,
  без облачного входа. Импорт/экспорт проекта включает медиа.
- Сортировка в последовательном режиме меняет переходы; в режиме ветвлений сохраняет связи.
- Редактор чужих готовых SCORM (включая iSpring) отложен на отдельный этап.
- Предложения без согласия пользователя (ИИ, облако, версии, дополнительные жесты,
  автоматические подсказки, выравнивание/блокировка областей и прочее) не входят в v0.6.

## Реализовано до v0.6
- Видео, скриншоты, несколько полей, горячие области, вопросы, текст/разбор, возврат.
- Ручная карта с портами/связями, группами, масштабом, поиском и авторасстановкой.
- Последствия решения могут идти через несколько видео и разбор, затем возврат к
  тому же выбору без повторного вводного видео; правильная ветка продолжает курс.
- Удаление/переименование/копирование шагов, пакетная загрузка, перетаскивание шагов
  и разделов, отмена/повтор. Несколько проектов, корзина и восстановление.
- Общий плеер для предпросмотра и SCORM 1.2. ZIP с медиа и манифестом без внешних запросов.
- Восстановление шага, позиции видео, числа ошибок. Оценка 100 минус штрафы.
- Явное «Завершить»: commit и LMSFinish; при отказе — повтор. Предпросмотр закрывается.
  Встроенный контейнер закрывает LMS; стандарт SCORM 1.2 не гарантирует закрытие iframe.
- Проверка match между полями по стабильным ID, включая регистр и пробелы;
  для сравнения в suspend_data сохраняются соль и отпечатки, а не текст пароля.

## Согласованные доработки v0.6 — реализовано
- Шапка задания: отдельное название задания, заметное «Задание», затем инструкция.
  Авторские названия шагов/файлов по-прежнему скрыты от сотрудника.
- Оформление курса: логотип PNG/JPG/WebP до 3 МБ, общий шрифт, основной цвет,
  цвет заголовков/текста. Параметры включаются в предпросмотр и SCORM.
- Начальная страница: название курса, логотип, описание, центральная кнопка «Начать».
  Новые пустые курсы получают её автоматически. В старом курсе добавляется через
  «Добавить материал → Начальная страница», без неявной перестройки старых веток.
- Шаблоны инструкции, карточек, диалога; редактируемый текст. Оформленный итог
  берёт название курса автоматически.
- Интерактивное видео: кнопки на последнем кадре или на заданной секунде с паузой;
  расположение/размер областей мышью, цвет кнопки и текста, размер шрифта, скругление.
  Полноэкранный режим включается для общего контейнера, сохраняя варианты при переходах.
  Работает при разрешении браузера/LMS; на устройстве без Fullscreen API доступен обычный режим.
- Прогресс: синяя сегментированная полоса сверху, сегмент на страницу маршрута.
  Для линейного курса — все страницы. Для веток — пройденные страницы и предполагаемый
  кратчайший оставшийся маршрут; пересчитывается после выбора. Возврат не дублирует сегменты.
- Новые проверки текста: несколько допустимых значений с новой строки, диапазон
  включительно (поддерживаются точка и запятая), формат почты/телефона; регистр и пробелы.
- Действия на экране: список, галочка, группа radio; начальное и правильное состояние.
  Несколько разных элементов на одном скриншоте, единая проверка перед продолжением.
- Autofill: источник «предыдущий шаг → поле», независимо от match. До 8 источников,
  по 64 символа. Значения Autofill сохраняются открытым текстом в данных прогресса LMS,
  о чём написано в настройках. Источники-пароли запрещены. Сравнение паролей остаётся хешированным.
  Исходное поле должно быть обязательным предшественником на всех ветках.
- Холст: копирование Ctrl/Cmd+C/V, перемещение стрелками (0.25%), изменение размера
  за восемь маркеров, масштаб 50–200%, Shift-выделение группы (также через список элементов),
  групповое перемещение/копирование/удаление. Справа — свойства выбранного элемента.
  Ссылки внутри скопированной группы получают новые ID. Горячие клавиши не мешают вводу текста.
- Новый учебный пример «Пример новых элементов»: готовая форма для проверки всех новых полей.
- Конвертер SCORM справа сверху, доступен и на главной. MP4 либо статический PPTX →
  видимая структура «обложка → материал/слайды → завершение», название, описание,
  цвет, шрифт и логотип. Открытие результата в редакторе или скачивание SCORM.
  Результат сохраняется отдельным проектом.

## Честные ограничения конвертера
- Прямой старый бинарный .ppt не поддержан: сначала сохранить как .pptx в PowerPoint.
  Полноценному преобразованию .ppt нужен отдельный движок/сервер, которого на GitHub Pages нет.
- PPTX импортируется локально в статические SVG: базовые тексты, фигуры, растровые
  изображения, часть мастер-слайдов. Это не движок PowerPoint: шрифты, переносы и
  сложная графика могут отличаться. Диаграммы/SmartArt/таблицы, анимации, переходы,
  встроенная озвучка/видео не воспроизводятся; в интерфейсе есть предупреждения.
  Перед публикацией автор обязан проверить слайды в предпросмотре.
- Кодеки MP4/WebM не конвертируются. Предпочтителен MP4 H.264. Автозапуск может
  требовать нажатия Play из-за политики браузера.
- 250 МБ медиа на проект; ZIP/JSON собираются в памяти. Нет ZIP64, SCORM 2004 и серверного хранения.
- Точное оформление и сценарии конкретной презентации проверяются на реальном файле.
- Совместимость с Mirapolis требует повторного тестового импорта нового ZIP.

## Структура
- model.js — проект, последовательность/граф, ссылки и адаптер курса.
- fields.js — общий контракт полей/ссылок для редактора и экспорта.
- player.js — общий автономный плеер; scorm.js — упаковка/API LMS.
- app.js — координация; outline.js — список; map.js — карта.
- areas.js — холст; field-ui.js — свойства выбранного элемента.
- course-ui.js — оформление; converter.js — поток конвертера; pptx.js — статический импорт.
- storage.js — IndexedDB/проекты; projects.js — библиотека/профиль; samples.js — пример.
- index.html, assets/css/author.css — каркас и оформление. dist/index.html генерируется.
