# Конструктор курсов — текущее состояние

Версия 0.4, 2026-11-03. Рабочий браузерный конструктор, без сервера.

## Решения
Белый и синий; строгий деловой интерфейс. Точный корпоративный HEX пока не задан.
Приложение называется «Конструктор курсов». Один курс может содержать любые материалы;
переключатель формата убран. Данные и координаты карты хранятся отдельно.
Главная страница — «Мои проекты», справа — честный локальный профиль без входа/облака.

## UX v0.4
- Несколько проектов в IndexedDB: список, даты, поиск, копирование, переименование,
  корзина и восстановление. Миграция прежнего current в библиотеку при обновлении БД.
- «Создать курс» предлагает пустой курс или учебный пример; прежние проекты не перезаписываются.
- Единое «Добавить материал»: пакетная загрузка видео/скриншотов создаёт отдельные шаги.
  Порядок файлов можно менять перед добавлением. Новые материалы идут в конец раздела;
  меню шага позволяет явно вставить после него. Замена — только отдельной командой.
- Список слева: перетаскивание шагов/разделов, альтернативные кнопки вверх/вниз,
  удаление через видимую кнопку/меню, подтверждение для непустых разделов и отмена.
- В последовательном режиме порядок в списке определяет переходы; итоговый экран остаётся
  последним. При ветвлении перестановка сохраняет ручные связи. Переключение к линейному
  режиму требует явного подтверждения; возвраты/несколько финалов нужно разобрать вручную.
- Обычные названия типов и пояснения; технические координаты скрыты в дополнительных настройках.
- «Посмотреть этот шаг» изолирует шаг от незавершённых остальных материалов.
- Поля настройки сохраняются сразу при вводе без необходимости нажимать Tab/Enter.
- Локальный профиль и проекты не являются облачным аккаунтом. Между устройствами — импорт/экспорт.
- Исходные CSS/JS получают версию в URL, чтобы старый кэш не ломал обновлённый интерфейс.

## Реализовано
- Загрузка видео MP4/WebM и скриншотов PNG/JPEG/WebP; локальная медиатека.
- Несколько полей поверх скриншота, выделение мышью; кнопка проверки на скриншоте.
- Точное значение, непустой текст и нормализованный URL; ошибки без перехода дальше.
- Кнопки выбора, радиоварианты с обязательным выбором, горячие области на скриншоте.
- Ручной граф: добавление/перетаскивание карточек, соединение портов, синхронный инспектор,
  несколько видеосцен в ветке, отложенные последствия, разбор и возврат к выбору.
- Успешная ветка ведёт к следующему сценарию. При возврате вводное видео не проигрывается;
  все варианты остаются доступны, история ошибок сохраняется.
- Группы сценариев со сворачиванием, сетка, авторасстановка по запросу, масштаб,
  поиск и обзор сценариев. Отмена/повтор изменений.
- Автосохранение в IndexedDB; скачивание/открытие проекта с медиа.
- Один проигрыватель для предпросмотра и SCORM; медиа без внешних запросов.
- SCORM 1.2: ZIP, манифест, API LMS, завершение и оценка, восстановление шага и позиции видео.
- Встроенный пробный курс из 14 шагов; демонстрационные клипы генерируются в браузере.

## Структура
assets/js/author/model.js — данные и операции графа.
storage.js — библиотека проектов IndexedDB и переносимый JSON с медиа.
projects.js — локальный профиль, карточки, корзина и создание курсов.
outline.js — список разделов/шагов, перетаскивание и действия.
map.js — редактор графа.
app.js — интерфейс и интеграция.
samples.js — создание тестовых материалов.
assets/css/author.css — деловое оформление.
modules/scorm/README.md — контракт экспортера; player.js — общий проигрыватель.
Внутренний scorm.js не читать при обычной правке интерфейса.

## Проверки
Автотесты SCORM/ZIP/XML/LMS lifecycle, модель графа, удаление связанных шагов,
отложенные последствия/возврат, несколько полей и восстановление видео.
В браузере пройдены: отрицательная ветка → разбор → возврат → положительная ветка →
скриншот/поле → клик → обязательный выбор → завершение; загрузка PNG, выделение поля,
изменение связей на карте и отмена.

## Практические ограничения
250 МБ медиа на проект; ZIP и переносимый JSON собираются в памяти.
Нет SCORM 2004, облачного хранения пользовательских курсов или совместного редактирования.
Кодеки не конвертируются. MP4 H.264 предпочтителен для совместимости.
Пример Gmail условный и не создаёт аккаунт. Для реального визуала нужны свои скриншоты.
Из-за политики автозапуска браузер может потребовать нажать Play.
Совместимость с Mirapolis не подтверждена: требуется тестовая загрузка.
GitHub: пользователь разрешил создание и публикацию репозитория konstruktor.

## Проверка UX v0.4
В браузере: перенос старого проекта, создание нового без перезаписи, пакет из трёх PNG,
добавление четвёртого, перетаскивание шага с изменением переходов, удаление раздела,
поле на скриншоте и проверка выбранного шага, несколько проектов, копия, корзина/восстановление,
локальный профиль. Модель проверяет порядок, ветки и сохранение итогового экрана.
