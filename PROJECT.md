# Сцена — текущее состояние

Версия 0.3, 2026-11-03. Рабочий браузерный конструктор, без сервера.

## Решения
Белый и синий; строгий деловой интерфейс. Точный корпоративный HEX пока не задан.
Единый курс объединяет видео и тренажёр. Разделы сверху фильтруют список шагов,
но не делят граф на независимые курсы. Данные и координаты карты хранятся отдельно.

## Реализовано
- Загрузка видео MP4/WebM и скриншотов PNG/JPEG/WebP; локальная медиатека.
- Несколько полей поверх скриншота, выделение мышью; кнопка проверки на скриншоте.
- Точное значение, непустой текст и нормализованный URL; ошибки без перехода дальше.
- Кнопки выбора, радиоварианты с обязательным выбором, горячие области на скриншоте.
- Ручной граф: добавление/перетаскивание карточек, соединение портов, синхронный инспектор,
  несколько видеосцен в ветке, отложенные последствия, разбор и возврат к выбору.
- Успешная ветка ведёт к следующему сценарию. При возврате вводное видео не проигрывается;
  все варианты остаются доступны, история ошибок сохраняется.
- Группы сценариев со сворачиванием, сетка, авторасстановка по запросу, масштаб,
  поиск и обзор сценариев. Отмена/повтор изменений.
- Автосохранение в IndexedDB; скачивание/открытие проекта с медиа.
- Один проигрыватель для предпросмотра и SCORM; медиа без внешних запросов.
- SCORM 1.2: ZIP, манифест, API LMS, завершение и оценка, восстановление шага и позиции видео.
- Встроенный пробный курс из 14 шагов; демонстрационные клипы генерируются в браузере.

## Структура
assets/js/author/model.js — данные и операции графа.
storage.js — IndexedDB и переносимый JSON с медиа.
map.js — редактор графа.
app.js — интерфейс и интеграция.
samples.js — создание тестовых материалов.
assets/css/author.css — деловое оформление.
modules/scorm/README.md — контракт экспортера; player.js — общий проигрыватель.
Внутренний scorm.js не читать при обычной правке интерфейса.

## Проверки
Автотесты SCORM/ZIP/XML/LMS lifecycle, модель графа, удаление связанных шагов,
отложенные последствия/возврат, несколько полей и восстановление видео.
В браузере пройдены: отрицательная ветка → разбор → возврат → положительная ветка →
скриншот/поле → клик → обязательный выбор → завершение; загрузка PNG, выделение поля,
изменение связей на карте и отмена.

## Практические ограничения
250 МБ медиа на проект; ZIP и переносимый JSON собираются в памяти.
Нет SCORM 2004, облачного хранения пользовательских курсов или совместного редактирования.
Кодеки не конвертируются. MP4 H.264 предпочтителен для совместимости.
Пример Gmail условный и не создаёт аккаунт. Для реального визуала нужны свои скриншоты.
Из-за политики автозапуска браузер может потребовать нажать Play.
Совместимость с Mirapolis не подтверждена: требуется тестовая загрузка.
