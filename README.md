# Сцена — конструктор учебных курсов

Рабочая браузерная версия в бело-синем корпоративном оформлении. Без сервера и npm-зависимостей.

## Быстрый старт
1. Откройте сайт и нажмите **Пробный курс**. Короткие видео и учебные скриншоты генерируются на устройстве.
2. Нажмите **Предпросмотр**. Выберите ошибочный ответ, досмотрите последствия и вернитесь к выбору.
3. Затем пройдите успешную ветку и регистрацию на скриншотах.
4. **Экспорт SCORM → Собрать и скачать ZIP**. Пакет предназначен для тестовой загрузки в LMS.
5. **Скачать проект** сохраняет редактируемый курс вместе с медиа. **Открыть проект** восстанавливает его.

## Свой курс
- Создайте новый курс, добавьте сценарии и шаги в левой панели.
- Видео: загрузите MP4/WebM, задайте следующий шаг. Для кнопок поверх последнего кадра
  добавьте отдельный **Выбор**, выберите в нём видео и свяжите его с исходной видеосценой.
- Тренажёр: добавьте **Поля ввода** или **Область нажатия**, загрузите PNG/JPEG/WebP.
  Выберите инструмент и обведите область мышью. Можно создать несколько полей на одном экране.
  Правила: точное значение, любой непустой текст, адрес сайта. Кнопка на скриншоте может проверять поля.
- Выбор: несколько вариантов, переходы или немедленная ошибка. Для отложенных последствий
  ведите вариант в видеоветку, затем в текстовый разбор и **Возврат к выбору**.
- Карта: перемещайте карточки за заголовок; тяните выход к входу либо нажмите их по очереди.
  Настройки справа и карта меняют один граф. Сценарии сворачиваются; доступны поиск,
  масштабирование, обзор сценариев, упорядочивание, отмена и повтор.
- Завершите курс узлом **Завершение курса** и выберите старт в настройках.

## Сохранение и файлы
Проект автоматически сохраняется в IndexedDB текущего браузера и текущего адреса сайта.
Очистка данных браузера удаляет локальную копию. Скачивайте файл проекта для переноса и резервной копии.
Файл `.scena.json` включает видео и скриншоты. Лимит медиа проекта — 250 МБ.
Большие видео лучше предварительно уменьшить: JSON и ZIP собираются в памяти браузера.
Материалы курса не отправляются на GitHub или другие серверы. На GitHub хранится только приложение.

## SCORM
SCORM 1.2, один SCO, медиа внутри ZIP. Сохраняются шаг, ошибки и позиция видео.
Возврат к выбору работает без повторного воспроизведения вводного видео.
Оценка: max(0,100−штраф×ошибки), штраф настраивается; завершение — completed.
Режимы обучения и проверки. Нет SCORM 2004, серверного совместного редактирования,
конвертации кодеков, ограничения перемотки или создания реальных аккаунтов Google.
Совместимость с Mirapolis необходимо подтвердить тестовым импортом в вашу LMS.

## Локальный запуск

    python3 -m http.server 8000 --bind 127.0.0.1

Откройте http://127.0.0.1:8000. Для автономного HTML:

    python3 scripts/build.py

Открыть `dist/index.html` в браузере. Автосохранение на file:// зависит от браузера;
если оно недоступно, используйте скачивание проекта или локальный HTTP-сервер.

## Проверки

    python3 scripts/check.py
    node tests/author.test.cjs
    node tests/branch-player.test.cjs
    node tests/scorm.test.cjs
    python3 scripts/check_scorm_zip.py

Python 3 и Node.js нужны только для проверок/сборки, не для опубликованного сайта.

## Карта кода
`PROJECT.md` — решения и статус. `AGENTS.md` — правила точечных правок.
`assets/js/author/` — модель, хранение, карта, интерфейс, пример.
`modules/scorm/README.md` — контракт экспортера. `player.js` — общий проигрыватель.
`scorm.js` — ZIP, манифест, SCORM API. Не изменяйте его при обычных правках интерфейса.

## GitHub Pages
Статический сайт публикуется из main / root. `.nojekyll` отключает обработку Jekyll.
Сборка на сервере не требуется: исходный index.html использует локальные CSS и JS.
Ключи доступа не нужны приложению и не должны попадать в репозиторий.
